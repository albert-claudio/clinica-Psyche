#Clinica Psicologica Psychê

Projeto desenvolvido para a AV3 da disciplina
Modelagem Orientada a Objetos.

## Objetivo

Modelar uma plataforma unificada destinada a profissionais
de Psicologia de diferentes áreas de atuação.
